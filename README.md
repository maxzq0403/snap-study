# ถ่ายไว้ก่อน — วิธี deploy เป็นเว็บแอปของตัวเอง

## สิ่งที่ต้องมีก่อน
1. บัญชี Netlify (สมัครฟรีที่ netlify.com ใช้ email หรือ GitHub ก็ได้)
2. Anthropic API key ของตัวเอง — สมัครที่ console.anthropic.com แล้วสร้าง key
   (การใช้งานคิดเงินตามจำนวนที่เรียก ไม่ใช่ฟรีเหมือนตอนอยู่ใน Claude.ai)

## ขั้นตอน deploy (ไม่ต้องเขียนโค้ดเพิ่ม)

1. ไปที่ https://app.netlify.com/drop
2. ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ (snap-study) ไปวางในหน้านั้น
3. รอสักครู่ Netlify จะให้ลิงก์เว็บมา เช่น `https://random-name-123.netlify.app`
4. ไปที่ **Site settings → Environment variables** ของไซต์นั้น
   เพิ่มตัวแปรชื่อ `ANTHROPIC_API_KEY` ค่าเป็น API key ที่คัดลอกมาจากขั้นตอนแรก
5. ไปที่ **Deploys → Trigger deploy** เพื่อให้ระบบรับค่า environment variable ใหม่
6. เปิดลิงก์เว็บแอปอีกครั้ง ลองถ่ายรูปดู ควรใช้งานได้ครบทุกฟังก์ชัน

## ติดตั้งเป็นไอคอนบนหน้าจอมือถือ
- **iPhone (Safari):** เปิดลิงก์เว็บแอป → กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome):** เปิดลิงก์เว็บแอป → เมนู 3 จุด → "ติดตั้งแอป" หรือ "เพิ่มไปยังหน้าจอโฮม"

หลังติดตั้งแล้วจะเปิดเหมือนแอปจริง ไม่มีแถบที่อยู่เว็บ (เพราะตั้งค่า manifest.json ไว้แล้ว)

## อยากได้ชื่อโดเมนของตัวเอง (เช่น snapstudy.com)
ทำได้ที่ **Site settings → Domain management** ของ Netlify — ซื้อโดเมนแล้วเชื่อมได้เลย
ไม่มีขั้นตอนนี้ก็ใช้ลิงก์ `.netlify.app` ฟรีไปก่อนได้

## หมายเหตุเรื่องความปลอดภัย
API key จะถูกเก็บเป็น environment variable ฝั่งเซิร์ฟเวอร์เท่านั้น (ใน `netlify/functions/claude.js`)
ไม่ปรากฏในโค้ดฝั่งเบราว์เซอร์เลย — ปลอดภัยสำหรับแชร์ลิงก์ให้เพื่อนใช้ด้วยได้
(แต่ทุกคนที่ใช้จะเรียก API ผ่าน key เดียวกัน ถ้าคนใช้เยอะค่าใช้จ่ายจะเพิ่มตามนั้น)
